The first release. Everything works on the built-in simulator. The ATEM connection is written and tested against a fake switcher, but it hasn't been used on a real one yet, so treat this as a version to try out before a show.

## What's in it

- Animated SuperSource takes. The layout waits on preview in its final form. At the take, the box for the source on program starts full screen, the switcher cuts while both pictures match, and the boxes move into place. Taking it out runs the other way and lands on the preview source.
- Boxes push each other by default, so neighbours ride against the box going full screen instead of sliding separately.
- Starter layouts from the Slide templates: Slides + presenter (and a pushed copy), two and three side boxes, Two up, Two presentations, Three portrait and Four up.
- SuperSources tab: the show's Active SuperSources in Companion button order, with the Library beside it.
- Design tab: drag, resize and crop boxes, grid and template overlays, fit a box to a template's cutout, and set every IN and OUT box by box. Changes stay as a draft until you save, with undo.
- Sources tab: map Presentation 1 to 4, Static, Wide and Camera 3 to 6 to inputs once per venue. M/E programs work as sources.
- Setup tab: find the switcher on the network, pick the M/E for takes, Companion settings, start with Windows and updates.
- Companion module for Companion 4.3 or later: SS CUT, SS AUTO and a button per layout with tally. Setup can fetch the module to your Downloads folder, ready for Modules, Import module package.
- Updates download in the background and install when the app quits.

## Known limits

- Not yet tested on an ATEM switcher.
- Takes stream from the PC frame by frame, so they want a steady wired network to the switcher.
- Layouts with five or six boxes aren't supported.
