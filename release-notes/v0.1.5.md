Animated takes now run as macros on the switcher. Not yet seen on a real switcher: try Test on preview first.

## Changes

- When you load a layout, the app writes each of its takes into a switcher macro. At SS CUT it only tells the switcher to run that macro, so the snap, the cut and every frame of movement play on the switcher's own clock. A busy PC or network can't make a take stutter.
- Macros go in slots 80 to 99 by default, a block of eight per SuperSource, with slot 99 kept for testing. Slots holding your own macros are never touched. Change the range in Setup, Takes.
- If a take's macro isn't on the switcher, the take cuts without animating. Setup can let it stream from this PC instead.
- Test on preview, in the Design tab, plays the selected take on the switcher while the layout is only on preview, without cutting.
- Setup shows how many of each loaded layout's takes are on the switcher.
- Setup, Debug shows what the next take will do and lists recent takes with the reason each one did or didn't animate, including takes made on the switcher panel, which can't animate.
- The snap now gets two frames before the cut, so a busy switcher can't show the old layout for a frame.

## Known limits

- Macro playback hasn't been watched on a switcher yet. Run Test on preview before using it on a show.
- Needs ATEM firmware 8.0 or later. Older switchers fall back as set in Setup.
