Fixes from the first day with 0.1.0. Still not tested on a real ATEM switcher.

## Changes

- New installs start in ATEM mode and ask for the switcher's IP address. The simulator is still there under Setup, Debug.
- The switcher address is saved the moment you set it, so if the app restarts mid-show it reconnects to the same switcher. The show file is written safely, so a crash while saving can't damage it.
- New shows map the ten sources to inputs 1 to 10, in the order the Sources tab lists them. Each dropdown starts with a greyed No selection line.
- Design tab: the selected box's outline and handles no longer draw over the layout settings popover or the More menu.
- Design tab: the IN and OUT tab labels are centred, and the lock icon on locked boxes is drawn properly.
