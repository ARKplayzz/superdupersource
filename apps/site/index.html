Animated SuperSource takes for Blackmagic ATEM switchers

The camera on program shrinks into its box while the slides come in beside it. Taking it out runs the other way and lands on whatever is on preview. The cut itself happens while both pictures are identical, so viewers don't see it.

Downloads What's new

Early release. The ATEM connection is written but hasn't been tested on a switcher yet, so the app also runs a built-in simulator.

How a take works

  1. Preview shows the finished layout

    Load a layout and it goes to preview in its final form, so the director sees exactly what will go to air.

  2. The cut is invisible

    At the take, the box holding the source already on program starts full screen and uncropped. Program looks the same before and after the cut.

  3. The boxes move into place

    Every box moves frame by frame, on its own timing and easing: 35 frames for a 700 ms move at 1080p50. Going out, the box for the source on preview grows to full screen, then the switcher cuts to that source.

Which box starts full screen depends on what's on air. If program is the presenter camera, the presenter box does. If it's ME2 showing that camera, it still matches, unless ME2 has a key on air. If nothing matches, the layout cuts in as a normal SuperSource.

Takes from Companion (SS CUT and SS AUTO) animate. Takes from the switcher panel or ATEM Software Control don't, because the app only hears about them after the switcher has already cut.

Design

Drag, resize and crop boxes over the background, with grids or one of your cutout templates laid over the top. A box fits a template's cutout in one click. Every source gets its own IN and OUT, set box by box along the bottom. Changes stay as a draft until you save.

Sources

Layouts name sources, not inputs: Presentation 1 to 4, Static, Wide and Camera 3 to 6. Set which input each one is once per venue, and every layout follows. An M/E's program works as a source too.

Companion

The app holds the show's Active SuperSources, in the order of the Companion buttons. The module gives you SS CUT, SS AUTO and a button per layout, green on preview and red on program. Needs Companion 4.3 or later.
